# Data usage disclosure

Publishing Center is a Pages context panel for SitecoreAI that shows whether
the current page is published and lets you publish, unpublish or delete it.
Reads, publishes, unpublishes and deletes go from the user's browser to
SitecoreAI through the Marketplace SDK, with the user's own permissions; the
app's server is only used to fetch public URLs the browser can't reach
across origins and to encrypt the optional Vercel protection bypass
password. The app has no database and no analytics.

Hosting: Vercel. Serverless functions run in the United States (Vercel
default region `iad1`, Washington, D.C.) unless the deployment sets another
region. In transit, all data uses TLS 1.2+ and HSTS.
